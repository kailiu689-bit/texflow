# Texflow 网页升级

用户要求同时优化编辑、排版体验、导入与复制，并修复公众号截图中的对齐告警。

保留原生静态网页和现有六套主题，不引入框架。相比只修复制告警，这次同时补齐内容保护；相比整站重写，改动集中在当前编辑与导出流程。

1. 统一整篇、手动编辑与分段复制的 HTML 清理路径。对齐仅输出 left/center/right/justify；计算样式从真实预览读取，避免脱离文档的节点丢失样式。测试覆盖 start/end、右到左方向、图片和文本框。
2. 保留预览 DOM 进行主题与字体切换；原文变化后提示用户按原文重排。增加撤销重做、标题/正文转换、图片插入与块移动。浏览器验证内容和图片位置。
3. 使用 IndexedDB 保存一个当前工作草稿（含图片、样式、手动修改），打开时恢复。保存失败明确提示；空白页面不覆盖已存草稿。验证刷新恢复与保存失败。
4. 保留墨绿纸色界面，增加主题缩略提示、段间距/页边距、375px 手机预览和窄屏布局。复制使用响应式尺寸，避免把桌面像素宽度带入公众号。
5. Word 导入保留图片顺序；导入失败恢复原稿；正文导出不丢手动修改。验证真实 DOCX 图文样本和剪贴板 HTML。

验收：浏览器回归通过；公开发布若执行，必须核验部署状态、资源可访问和线上交互。微信后台告警是否消失需在实际后台复核，不以本地检查代替。
