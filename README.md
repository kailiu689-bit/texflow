# TeXflow 公众号排版工作台

线上入口：https://kailiu689-bit.github.io/texflow/

静态网页，无需构建。当前升级版本：2026.10。

- 在原文区输入文字或导入 Word/PDF；右侧可继续编辑。
- 切换主题、配色和字体会保留右侧修改。修改原文后，点“一键排版”才重新生成；撤销可找回此前内容。
- 撤销/重做支持按钮和 Ctrl/⌘ Z、Ctrl/⌘ Shift Z。
- 点选预览内容后，可转换标题/正文、移动或删除内容块；“插图”把图片放到选中内容后。
- 字体设置中可调整段间距与正文边距。“手机预览”以 375px 宽度查看排版。
- 当前工作草稿（含图片和样式）自动保存到本机浏览器的 IndexedDB，打开同一网址会恢复。顶部显示保存状态，也可手动保存。清除站点数据会删除本机草稿；需要长期备份时导出文章。
- 复制整篇和分段内容均使用同一套公众号兼容 HTML。对齐值会转为 left/center/right/justify；图片压缩失败会标明补图位置。
- 旧版二进制 DOC/WPS 请另存为 DOCX。PDF 以原页面图片保留版面，同时提取文字。

## 本地查看

```sh
python3 -m http.server 8765
```

打开 http://localhost:8765 。本机测试与线上网址属于不同来源，草稿分别保存。

## 浏览器回归

需要 Node.js、Playwright 和 Chrome。设置好 Playwright 依赖后：

```sh
node tests/browser-regression.cjs
```

测试会启动临时本地服务器，覆盖编辑保护、撤销重做、IndexedDB 恢复、Word/PDF 导入、真实剪贴板 HTML、导出及窄屏布局。测试截图与结果存于 `tests/.artifacts/`（不提交）。若设置 `TEXFLOW_TEST_URL`，会在该网址运行同一组测试。测试均使用独立浏览器会话，不修改用户浏览器的草稿。

本地检查覆盖所见的非法对齐值；微信后台的最终结构检测与手机显示仍应以实际粘贴预览为准。
